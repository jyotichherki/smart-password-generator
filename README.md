# 🔐 Smart Password Generator

A responsive password generator built using **HTML, CSS, and JavaScript**. It creates secure random passwords with customizable length and character options.

### Features
- Adjustable password length
- Uppercase and lowercase letters
- Numbers and special symbols
- Secure random password generation
- One-click copy-to-clipboard
- Animated success notifications

### Technologies Used
HTML • CSS • JavaScript • Clipboard API • DOM Manipulation

### How to Run
1. Download or clone the repository.
2. Open `index.html` in your browser or use Live Server.
3. Customize your options and generate a password.
